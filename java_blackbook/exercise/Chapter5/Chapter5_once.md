    ②答えの導き方
    ③どういうことが分かっていないのか、どの点が理解不足かを書く。なければ書かない。
1.  D
    ABCはParentクラスになくても継承できるが、Childクラスではフィールドを記述していないため、親クラスがフィールドを定義していないと、フィールドにアクセスしようとしているメソッドが動かなくなってしまうため。
2.  C
    ABDは説明が間違っているため。正しい説明がCだけであるため。アクセス修飾子がつかないデフォルトのフィールドは同一パッケージのみアクセス可能である。アクセス修飾子がprivateであるメソッドは、同クラス内でのみアクセスできる。protectedなメソッドは、同一パッケージまたは継承先のサブクラスがアクセスできる。
3.  AE
    BCDは説明が間違っているため。Bはstaticなフィールドなら定義可能であるため間違い。Cはインタフェースは、抽象メソッドであるので、メソッドの衝突が起きないため多重継承できるため間違い。Dはインタフェースは継承できるため間違い。
4.  A
    プログラムを正しく動作させるにはAのインタフェースでデフォルトメソッドにすることが必要であり、それ以外は正しくないため。Bはインタフェースは抽象メソッドがないとインタフェースでなくなるため、Cは、このままならコンパイルエラーになり、例外はスローされないため。Dはこのままではコンパイルエラーになり、正しく実行されないため。
5.  A
    Overrideできない所で@Overrideを書いているため、コンパイルエラーコンパイルエラーにならないならC。
    @OverrideがOverrideする必要のないクラスで、あるいはメソッドの直前に書くことがコンパイルエラーになるのかどうかが分からない。@Overrideの運用ルール、文法が分からない。
